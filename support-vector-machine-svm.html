Support Vector Machine (SVM)

📌 การทำงานของอัลกอริทึม

ค้นหาเส้นหรือระนาบแบ่งขอบเขต (Hyperplane) ที่สร้างระยะห่าง (Margin) ระหว่างข้อมูล 2 คลาสได้กว้างที่สุดเท่าที่เป็นไปได้
* C Parameter: ตัวปรับความเข้มงวดของ Margin ค่า C สูงจะไม่ยอมให้มีจุดข้อมูลข้ามฝั่ง (Hard Margin) ส่วน C ต่ำจะผ่อนปรนให้ข้ามได้บ้าง (Soft Margin)
