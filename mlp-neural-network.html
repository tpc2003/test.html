MLP Neural Network

📌 การทำงานของอัลกอริทึม

โครงข่ายประสาทเทียมแบบป้อนหน้า (Feedforward) ประกอบด้วย Input Layer, Hidden Layers และ Output Layer ใช้หลักการ Backpropagation ปรับค่าน้ำหนัก (Weights) เพื่อลดค่า Error (Loss)
* Learning Rate ($\eta$): อัตราการเรียนรู้ในการปรับ Weights
* Hidden Neurons: จำนวนโหนดประมวลผลในเลเยอร์ซ่อน
