CNN Architecture

📌 การทำงานของอัลกอริทึม

ประมวลผลข้อมูลภาพหรือโครงสร้าง grid โดยใช้ Filter/Kernel เลื่อนสแกนทั่วภาพเพื่อสกัดเอารักษณะเด่น (Features) เช่น เส้น ขอบ ออกมาเป็น Feature Map
* Kernel Size: ขนาดตารางหน้าต่าง Filter ที่ใช้สแกน
* Stride: ระยะการก้าวขยับของ Filter ในแต่ละช่อง
