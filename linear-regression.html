Linear Regression

📌 การทำงานของอัลกอริทึม

ทำนายค่าเชิงตัวเลขแบบต่อเนื่อง (Continuous Value) โดยหาความสัมพันธ์เชิงเส้นตรงระหว่างตัวแปรอิสระ (X) และตัวแปรตาม (Y) ให้อยู่ในรูปสมการ Y = mX + c
* Slope (m): กำหนดอัตราการเปลี่ยนแปลงหรือความชันของเส้นทำนาย
* Intercept (c): จุดที่เส้นตรงตัดแกน Y เมื่อ X = 0
* Noise: สัญญาณรบกวนในชุดข้อมูล จำลองความคลาดเคลื่อนในชีวิตจริง
