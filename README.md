9. `09-cnn.html`
10. `10-lstm.html`
11. `11-transformer.html`
12. `12-reinforcement-learning.html`
13. `13-xgboost.html`
14. `14-stacking.html`

> Note: CNN, LSTM, and Transformer are deep-learning architectures and are commonly used in supervised/self-supervised settings; K-Means is unsupervised. The files follow the requested numbering while labeling the learning type more accurately.

## GitHub

Create a repository, then upload all `.html` files and this README. Each HTML file is standalone and does not require external libraries.

Example Git commands:

```bash
git init
git add .
git commit -m "Add ML algorithm visualizations"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

For GitHub Pages, enable **Settings → Pages → Deploy from a branch → main / root**.
